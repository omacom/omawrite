# A quieter place to write

Write Markdown, not a document format. Keep **bold ideas**, *small details*,
and [useful links](https://github.com/omacom/omawrite) in plain text.

## From outline to working draft

- Keep your original Markdown on disk.
- Switch between **Edit** and **Read** without losing your place.
- Copy code, select text, and undo changes as usual.

> A native editor can show the shape of a document without hiding its source.

```cpp
#include <QString>

QString greeting(const QString &name) {
    return QStringLiteral("Hello, %1!").arg(name);
}
```

Inline `code` stays readable. Move the caret into a styled span to reveal
its Markdown markers; move away to return to the preview.
