# References without leaving the page

A footnote can carry the detail[^details] while the paragraph stays focused.
Hover the little number to preview the note; follow it to its definition.

Reference-style links work too: read the [project documentation][project]
or reuse the same destination in a [second link][project].

## Keep the source portable

- **Ctrl/Cmd + K** inserts an inline link.
- **Ctrl/Cmd + Shift + K** inserts a reference-style link and definition.
- **Ctrl/Cmd + Alt/Option + K** inserts a footnote and definition.

The insertion shortcuts can use the clipboard. Footnotes use selected text
as the note body, then clipboard text when nothing is selected.

[^details]: Notes can contain **formatted text**, several lines, and links.
    The hover preview is plain text, so a quick glance never opens a browser.

[project]: https://github.com/omacom/omawrite
