# Triage Labels

The skills use five canonical triage roles. In this local tracker, use the
matching string in the ticket's `Status:` line.

| Canonical role | Status |
| --- | --- |
| `needs-triage` | `needs-triage` |
| `needs-info` | `needs-info` |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix` | `wontfix` |
