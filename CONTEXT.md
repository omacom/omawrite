# Omawrite

Omawrite is a focused Markdown writing application. It preserves the source
document while offering a separate reading surface.

## Language

**Preview**:
A read-only rendering of the current Markdown source, distinct from the editor.
_Avoid_: WYSIWYG editor, rendered editor

**Local image**:
An image referenced by a relative path contained in the Markdown document's directory.
_Avoid_: Remote image, embedded image
